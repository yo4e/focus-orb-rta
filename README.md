# Focus Orb

A small browser-based focus timer with an animated orb and particle background.

## Use

Open `index.html` in a modern browser. The default session is 25 minutes; use the + / − controls to adjust the duration, then click the orb/timer area to start focusing.

No build step or package installation is required.

## Files

- `index.html` — page structure and controls
- `script.js` — timer and visual behavior
- `style.css` — layout and styling

The page loads the Outfit font from Google Fonts at runtime. That font is provided under its own license and is not included in this repository.
